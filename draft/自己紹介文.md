# 自己紹介文（確定版）

方針：家計ツール一本／資格の話は書かない／家庭の話は触れない

---

## Instagram プロフィール

```
数字を切り上げない家計シミュレーションを作りました。
固定資産税も車の買替も介護費も最初から入っていて、
結果は額面ではなく「今のお金」で出ます。
甘い数字で安心するのが、いちばんあぶないので。↓
```
（約95字）

### 短くしたい場合
```
数字を切り上げない家計シミュレーションを作りました。
額面ではなく「今のお金」で50年先まで出ます。
無料・登録不要 ↓
```
（約58字）

---

## note プロフィール

```
家計シミュレーション「家計の50年」を作って、公開しています。

年齢と手取り年収を入れるだけで、50年先までの資産推移が出ます。
教育費も年金も介護費も、公的統計から数字を取り直して入れました。

作りながら何度も方針を変えました。
最初に置いていたサンプルの家庭は消しましたし、
入れようとしてやめた計算もあります。

そういう、うまくいかなかったほうの話を書いています。
```

### 短くしたい場合
```
家計シミュレーション「家計の50年」を作りました。
数字は全部、公的統計から取り直しています。
作る過程で何を間違えて、どこで方針を変えたのかを書いています。
```

## X プロフィール

```
家計シミュレーション「家計の50年」を作りました。
年齢と手取り年収を入れるだけ。数字は公的統計から取り直し。
額面ではなく「今のお金」で出ます。無料・登録不要。
作った話はnoteに。
```
（約95字）

### ひとこと版
```
家計シミュレーション「家計の50年」を作った人。数字は切り上げない主義。
```
（約35字）
