# 家計の50年

年齢と収入を入れるだけで、生涯の資産推移を年ごとに試算するツールです。

**https://winnow-00.github.io/kakei50/**

`index.html` 一枚で完結しています。ビルド不要、サーバー不要、外部への送信なし。
入力内容は閲覧者自身のブラウザ（localStorage）にだけ保存されます。

## 標準値の出典

細かい数字を調べなくても使えるよう、以下の公的統計にもとづく標準値を入れてあります。
画面上の各セクションにも出典を明記しています。

| 項目 | 出典 |
|---|---|
| 教育費（幼稚園〜高校） | 文部科学省「令和5年度 子供の学習費調査」学習費総額 |
| 教育費（大学） | 日本政策金融公庫「令和3年度 教育費負担の実態調査」 |
| 生活費・可処分所得 | 総務省「家計調査」2025年平均 |
| 年金 | 日本年金機構（令和8年度の年金額） |
| 介護費 | 生命保険文化センター「2024年度 生命保険に関する全国実態調査」 |

教育費エンジンは出典の公表合計を再現します（幼〜高すべて公立で617万／文科省の公表値614万、
大学は国公立・私立文系・私立理系の3種とも公表値と一致）。標準値を変更した場合は、
この照合をやり直してください。

## 計算の不変条件

数式を触ったら、全年で以下が成り立つことを確認してください。

1. 収入 − 固定支出 − 教育費 − 特別支出 − 積立額 ＋ 取崩 ＝ 現金増減
2. グラフの三層（現金・投資元本・運用益）の合計 ＝ 現金 ＋ 投資評価額
3. 同じ年に「積立」と「取り崩し」が同時に起きない

## 既知の制約

- 運用益は毎年一定率の複利計算。値動きの順序（退職直後の暴落など）は表現していません
- **配偶者が先に亡くなった後を計算していません。**世帯の年金は下がるのに生活費は半分にならない局面です
- 収入はすべて手取り扱い。投資の取り崩しにも課税していません
- 将来の税制・年金制度・教育費の変更は反映していません

## これは金融アドバイスではありません

一般的な試算ツールです。実際の判断の前に、ねんきん定期便・退職金規程・ローンの返済予定表などの
実書類と突き合わせ、金融機関やファイナンシャルプランナーにご相談ください。
